# YTLoadster

YTLoadster — настольное приложение для скачивания видео, аудио и субтитров с поддерживаемых сайтов. Оно использует Tauri 2, Rust, React, TypeScript и `yt-dlp`.

> Проект находится на стадии тестового выпуска `0.1.0`. Windows остаётся основной платформой разработки, а macOS-сборки проходят отдельное тестирование. Используйте приложение в соответствии с правилами сайтов, законодательством и правами правообладателей.

## Возможности

- Автоматический анализ ссылки и выбор доступных вариантов качества.
- Загрузка видео, аудио и субтитров.
- Готовые видеопрофили для телефона, планшета, Smart TV и совместимого MP4.
- Ручной выбор разрешения, FPS, контейнера и кодека.
- Очередь с прогрессом, скоростью, паузой, отменой и повтором заданий.
- Выбор папки, языка интерфейса, темы, числа параллельных загрузок и сетевых фрагментов.
- Отдельный вход в YouTube для роликов с ограничениями: приложение создаёт изолированный профиль браузера и не затрагивает обычный профиль пользователя.
- Встроенные `yt-dlp`, Deno, FFmpeg и FFprobe в release-сборках: пользователю не требуется устанавливать их вручную.

## Платформы и релизы

- **Windows 10/11 x64** — основной целевой выпуск; готовится как portable-архив.
- **macOS 12+** — GitHub Actions собирает отдельные тестовые DMG для Apple Silicon (`arm64`) и Intel (`x64`). Apple Silicon-вариант проверен на MacBook Pro с M4: загрузка и объединение видео/аудио, конвертация в MP3 и встраивание обложки работают со встроенными инструментами без Homebrew.

macOS-тестовые сборки подписываются ad-hoc и пока не имеют Developer ID или notarization. Поэтому Gatekeeper может потребовать разрешить первый запуск в настройках безопасности macOS. Intel DMG собирается тем же воспроизводимым workflow, но до выпуска требует отдельного ручного теста на Intel Mac.

Windows portable пока также не имеет цифровой подписи. Проверка файла Microsoft Defender не заменяет code signing, поэтому SmartScreen может показать предупреждение.

## Запуск из исходников

Нужны Node.js 22+, Rust и системные зависимости Tauri для вашей платформы.

```powershell
npm.cmd install
npm.cmd run tauri -- dev
```

Команды выполняются из корня репозитория. Для macOS и Linux используйте `npm` вместо `npm.cmd`.

## Конфиденциальность и вход в YouTube

Для сценария «Войти в YouTube» приложение открывает отдельный профиль установленного Chromium-браузера. После завершения входа сохраняются только cookies YouTube: на Windows они защищены DPAPI, на macOS — системной Связкой ключей. Пароль пользователя приложение не получает; основной профиль браузера и уже открытые окна не изменяются.

Чтение cookies из обычного браузера предназначено для разовых случаев. macOS может запросить доступ к Связке ключей Chrome; Safari может ограничивать доступ к собственному хранилищу cookies.

## Сторонние компоненты

Release-сборки используют `yt-dlp`, Deno, FFmpeg и FFprobe; macOS-сборка FFmpeg дополнительно использует LAME для MP3. Все инструменты включаются в пакет приложения, а их версии и SHA-256 фиксируются при упаковке. Уведомления о компонентах и лицензиях находятся в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
