# YTLoadster

[English](README.en.md)

YTLoadster - настольное приложение для скачивания видео, аудио и субтитров с поддерживаемых сайтов.

> Это первый публичный выпуск `0.1.0` для Windows и macOS. Используйте приложение в соответствии с правилами сайтов, законодательством и правами правообладателей.

## Возможности

- Автоматический анализ ссылки и выбор доступных вариантов качества.
- Загрузка видео, аудио и субтитров.
- Готовые видеопрофили для телефона, планшета, Smart TV и совместимого MP4.
- Ручной выбор разрешения, FPS, контейнера и кодека.
- Возможно приостанавливать/возобновлять/отменять загрузку.
- Выбор числа параллельных загрузок и сетевых фрагментов.
- Темная/светлая темы.
- Отдельный вход в YouTube для роликов с ограничениями: приложение создаёт изолированный профиль браузера и не затрагивает обычный профиль пользователя.
- Загрузка видео, для которых требуется авторизация, с использованием cookies.

## Платформы и релизы

- **Windows 10/11 x64** - распространяется как portable-архив.
- **macOS 12+** - распространяется отдельными DMG для Apple Silicon (`arm64`) и Intel (`x64`).

## Установка

### Windows

Распакуйте ZIP целиком и запустите `YTLoadster.exe`. Не переносите EXE отдельно от папки `tools`.

Сборка пока не имеет цифровой подписи. Если архив скачан именно со страницы Releases официального репозитория, в предупреждении SmartScreen нажмите «Подробнее», проверьте имя `YTLoadster` и выберите «Выполнить в любом случае». Не запускайте файл, полученный из другого источника.

### macOS

Откройте DMG и перетащите YTLoadster в `Applications`.

Сборка подписана ad-hoc и пока не нотарифицирована Apple. Если Gatekeeper заблокирует первый запуск, откройте «Системные настройки» → «Конфиденциальность и безопасность», найдите сообщение о YTLoadster и нажмите «Всё равно открыть».

Если этот способ недоступен, снимите атрибут карантина в Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/YTLoadster.app"
```

После выполнения команды снова откройте YTLoadster из папки `Applications`.

## Важно

Используйте приложение только для материалов, которые вы имеете право скачивать. Пользователь самостоятельно отвечает за соблюдение условий сайтов, авторских прав и законодательства своей страны.

## Запуск из исходников

Нужны Node.js 22+, Rust и системные зависимости Tauri для вашей платформы.

```powershell
npm.cmd install
npm.cmd run tauri -- dev
```

Команды выполняются из корня репозитория. Для macOS и Linux используйте `npm` вместо `npm.cmd`.

## Конфиденциальность и вход в YouTube

Для сценария «Войти в YouTube» приложение открывает отдельный профиль установленного Chromium-браузера и выбранного по умолчанию. После завершения входа сохраняются только cookies YouTube: на Windows они защищены DPAPI, на macOS - системной Связкой ключей. Пароль пользователя приложение не получает; основной профиль браузера и уже открытые окна не изменяются.

Чтение cookies из обычного браузера предназначено для разовых случаев. macOS может запросить доступ к Связке ключей Chrome; Safari может ограничивать доступ к собственному хранилищу cookies.
