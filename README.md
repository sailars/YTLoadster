# YTLoadster

[English](README.en.md)

YTLoadster - настольное приложение для скачивания видео, аудио и субтитров с YouTube.

> Актуальная версия - `0.1.1` для Windows и macOS. Используйте приложение в соответствии с правилами сайтов, законодательством и правами правообладателей.

## Возможности

- Автоматический анализ ссылки YouTube и выбор доступных вариантов качества.
- Загрузка видео, аудио и субтитров с YouTube.
- Загрузка выбранных видео, аудио и субтитров из YouTube-плейлистов.
- Для плейлистов можно выбрать точное качество или автоматический подбор ближайшего доступного варианта.
- Готовые видеопрофили для телефона, планшета, Smart TV и совместимого MP4.
- Управление очередью загрузок: приостанавливайте, продолжайте, отменяйте и повторяйте загрузки.
- История успешно загруженных файлов
- Выбор числа параллельных загрузок и соединений (фрагментов) на видео.
- Возможность настройки пользовательского User-Agent для анализа и загрузки.
- Блокировка сна во время активных загрузок.
- Тёмная тема.
- Авторизация через cookies браузера.
- Авторизация в YouTube с помощью изолированного профиля браузера. Не затрагивает обычный профиль пользователя.

## Настройки ветки v0.1.2

Настройки открываются отдельным разделом боковой панели. В "Общих" находятся язык, звук завершения, блокировка сна, сворачивание в трей и автоматическая проверка обновлений. В "Загрузках" можно выбрать папку по умолчанию для новых одиночных загрузок и плейлистов, шаблон имени файла, действие при совпадении имён (переименовать или заменить), число параллельных загрузок и фрагментов, подбор форматов плейлиста и повторные попытки. Папку конкретной загрузки по-прежнему можно изменить перед постановкой в очередь.

В "Сети" доступны системный режим, режим "Без прокси" и ручные HTTP, HTTPS и SOCKS5 с логином и паролем, а также пользовательский User-Agent. Системный режим и отключение прокси применяются сразу; для ручного прокси нужно заполнить параметры и нажать "Сохранить". Режим "Без прокси" не добавляет собственный прокси приложения и не отключает системную маршрутизацию, VPN и системные прокси-клиенты. Пароль прокси защищён средствами ОС: DPAPI на Windows и Связкой ключей на macOS. "Авторизация" содержит прежние варианты входа. В "Внешнем виде" можно выбрать тему, акцентный цвет и отображение миниатюр в плейлисте, очереди и истории. Очередь после перезапуска приложения пока не восстанавливается.

## Платформы и релизы

- **Windows 10/11 x64** - распространяется как portable-архив.
- **macOS 12+** - распространяется отдельными DMG для Apple Silicon (`arm64`) и Intel (`x64`).

## Установка

### Windows

Распакуйте ZIP целиком и запустите `YTLoadster.exe`. Не переносите EXE отдельно от папки `tools`.

Сборка пока не имеет цифровой подписи. Если архив скачан именно со страницы Releases официального репозитория, в предупреждении SmartScreen нажмите «Подробнее», проверьте имя `YTLoadster` и выберите «Выполнить в любом случае». Не запускайте файл, полученный из другого источника.

### macOS

Откройте DMG и перетащите YTLoadster в `Applications`.

Сборка подписана ad-hoc и пока не нотарифицирована Apple. Если Gatekeeper заблокирует первый запуск, откройте «Системные настройки» → «Конфиденциальность и безопасность», найдите сообщение о YTLoadster и нажмите «Всё равно открыть».

Если этот способ недоступен, снимите атрибут карантина в Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/YTLoadster.app"
```

После выполнения команды снова откройте YTLoadster из папки `Applications`.

## Важно

Используйте приложение только для материалов, которые вы имеете право скачивать. Пользователь самостоятельно отвечает за соблюдение условий сайтов, авторских прав и законодательства своей страны.

## Запуск из исходников

Нужны Node.js 22+, Rust и системные зависимости Tauri для вашей платформы.

```powershell
npm.cmd install
npm.cmd run tauri -- dev
```

Команды выполняются из корня репозитория. Для macOS и Linux используйте `npm` вместо `npm.cmd`.

## Конфиденциальность и вход в YouTube

Для сценария "Войти в YouTube" приложение открывает отдельный профиль выбранного установленного Chromium-браузера. После завершения входа сохраняются только cookies YouTube: на Windows они защищены DPAPI, на macOS - системной Связкой ключей. Пароль пользователя приложение не получает; основной профиль браузера и уже открытые окна не изменяются.

После входа дождитесь открытия YouTube и сообщения о выполненном входе в YTLoadster. Сессия подхватывается автоматически на Windows и macOS, и сразу можно анализировать ссылки и скачивать видео. Окно можно оставить открытым: программа обновляет cookies в фоне и получает свежий снимок перед анализом ссылки и запуском задания из очереди. После закрытия отдельного окна, в том числе через Cmd+Q на macOS, используется последняя защищённая сессия, пока она действительна; временный профиль удаляется. Если выйти из аккаунта в отдельном окне, сохранённая сессия удаляется до следующего входа. Во время входа macOS может показывать второй значок браузера в Dock.

Чтение cookies из обычного браузера предназначено для разовых случаев. macOS может запросить доступ к Связке ключей Chrome; Safari может ограничивать доступ к собственному хранилищу cookies.

## Сторонние компоненты

Release-сборки используют `yt-dlp`, Deno, FFmpeg и FFprobe; macOS-сборка FFmpeg дополнительно использует LAME для MP3. Все инструменты включаются в пакет приложения. Их условия распространения описаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Разрешённый граф frontend- и Rust-зависимостей зафиксирован в [licenses/DEPENDENCIES.md](licenses/DEPENDENCIES.md); фактические уведомления frontend-компонентов находятся в [licenses/FRONTEND_LICENSES.txt](licenses/FRONTEND_LICENSES.txt), а полный отчёт с текстами лицензий Rust-компонентов - в [licenses/DEPENDENCY_LICENSES.html](licenses/DEPENDENCY_LICENSES.html).

В разделе "Настройки" → "О программе" есть отдельная проверка обновлений компонентов. После проверки можно установить доступные версии `yt-dlp`, Deno и комплекта FFmpeg/FFprobe без обновления YTLoadster. На Windows FFmpeg загружается из LGPL shared-сборок BtbN; на macOS FFmpeg/FFprobe и LAME обновляются вместе из проверенного выпуска компонентов YTLoadster, когда он опубликован. Если подходящего выпуска нет, приложение сверяет установленную версию FFmpeg с официальными выпусками. Подтверждённая актуальная версия показывается как последняя; более новая официальная версия без пакета приложения показывается со ссылкой на выпуск, без кнопки установки.

Загруженные файлы проверяются по SHA-256 из GitHub Releases и запускаются для проверки версии. На Windows обновление заменяет исходные компоненты в папке portable-приложения; FFmpeg, FFprobe и DLL заменяются вместе. Папка приложения должна быть доступна для записи. На macOS компоненты сохраняются в каталоге данных пользователя, чтобы не изменять `.app`. Уже выполняющиеся задания завершаются со своими запущенными компонентами; новые задания используют установленную версию. Проверка компонентов выполняется только по нажатию кнопки.
