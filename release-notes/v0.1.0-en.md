# YTLoadster 0.1.0

The first public YTLoadster release for Windows and macOS.

## Features

- automatically analyzes a URL and lists the available quality options;
- downloads video, audio, manual subtitles, and automatic captions;
- merges separate video and audio streams;
- provides presets for phones, tablets, Smart TVs, and compatible MP4;
- allows manual selection of resolution, frame rate, container, codec, and
  audio format;
- converts audio, writes metadata, and embeds cover art;
- manages a download queue with pause, resume, cancel, clear, and retry
  actions;
- supports light and dark themes and Russian and English interfaces;
- provides an isolated YouTube sign-in flow for content that requires an
  account or age confirmation;
- includes yt-dlp, Deno, FFmpeg, and FFprobe, with no separate installation
  required.

## Installation

### Windows

Extract the entire ZIP archive and run `YTLoadster.exe`. Do not move the EXE
away from the `tools` directory.

This build is not digitally signed yet. If the archive came from the Releases
page of the official repository, select “More info” in the SmartScreen dialog,
verify the `YTLoadster` application name, and choose “Run anyway”. Do not run a
copy obtained from another source.

### macOS

Open the DMG and drag YTLoadster to `Applications`.

This build uses an ad-hoc signature and is not notarized by Apple yet. If
Gatekeeper blocks the first launch, open System Settings → Privacy & Security,
find the YTLoadster message, and choose “Open Anyway”.
